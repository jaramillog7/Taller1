Solución taller
1. ¿Qué es HTML y cuál es su función en la web?
HTML es un lenguaje que se utiliza para crear y organizar el contenido de una página web, como textos, imágenes, botones, enlaces y títulos.
2. ¿Qué es una etiqueta HTML y menciona las etiquetas más comunes?
Una etiqueta HTML sirve para indicar qué tipo de contenido hay en una página.
Las etiquetas más comunes son las siguientes:
•	<h1> para títulos.
•	<p> para párrafos.
•	<img> para imágenes.
•	<a> para enlaces. 
•	<div> para organizar contenido.
3. ¿Qué es un atributo de una etiqueta HTML y menciona los más comunes?
Un atributo agrega información o características adicionales a una etiqueta. 
Los atributos más comunes son los siguientes:
•	id: identifica un elemento de forma única. 
•	class: permite agrupar elementos para aplicarles estilos. 
•	href: indica la dirección a la que lleva un enlace. 
•	src: indica la ubicación de una imagen u otro archivo. 
•	alt: agrega una descripción alternativa a una imagen. 
•	title: muestra información adicional sobre un elemento. 
•	style: permite agregar estilos CSS directamente al elemento.
4. ¿Qué es CSS y cómo se utiliza para el diseño web?
CSS es el lenguaje que se utiliza para darle diseño y estilo a una página web. Permite cambiar colores, tamaños, fuentes, espacios y la posición de los elementos.
5. ¿Qué es una propiedad en CSS y menciona las propiedades más comunes?
Una propiedad en CSS sirve para indicar qué característica o aspecto de un elemento HTML queremos modificar. Algunas de las más comunes son:
•	color: cambia el color del texto. 
•	background-color: cambia el color de fondo. 
•	font-size: cambia el tamaño del texto. 
•	font-family: cambia el tipo de letra. 
•	width: define el ancho de un elemento. 
•	height: define la altura de un elemento. 
•	margin: agrega espacio por fuera del elemento. 
•	padding: agrega espacio dentro del elemento. 
•	border: permite agregar y modificar los bordes.
6. ¿Qué es un selector en CSS y cuáles tipos existen?
Un selector sirve para escoger qué elementos HTML queremos modificar. Los más utilizados son por etiqueta, por clase (.clase) y por identificador (#id).
7. ¿Qué es JavaScript y cómo añade interactividad a las páginas web?
JavaScript es un lenguaje de programación que permite hacer que una página web sea interactiva, por ejemplo, responder a botones, mostrar mensajes o cambiar contenido.
8. ¿Cuáles son los tipos de datos primitivos en JavaScript?
Son los tipos de datos básicos que maneja JavaScript. Algunos son string (texto), number (números), boolean (verdadero o falso), undefined, null, bigint y symbol.
9. ¿Cómo funcionan las estructuras de control de flujo como if, else, switch y bucles en JavaScript?
Sirven para controlar lo que hace un programa. if y else permiten tomar decisiones, switch permite elegir entre varias opciones y los bucles permiten repetir instrucciones.
10. ¿Por qué es importante usar nombres significativos para variables y métodos?
Porque ayudan a entender mejor el código. Por ejemplo, es más claro usar nombreUsuario que simplemente usar una variable llamada x.
11. ¿Qué es una variable de entorno y por qué son importantes para JavaScript o la programación en general?
Es una variable que guarda información de configuración fuera del código, como contraseñas, claves o direcciones. Ayuda a mantener estos datos organizados y más seguros.
12. ¿Qué son las herramientas de desarrollo de Chrome y cómo se accede a ellas?
Son herramientas que trae Chrome para revisar y probar páginas web. Se pueden abrir presionando F12 o haciendo clic derecho en la página y seleccionando Inspeccionar.
13. ¿Qué se puede hacer en el panel "Elements" de las herramientas de desarrollo?
Permite ver el HTML y CSS de una página y hacer cambios temporales para probar cómo se vería.
14. ¿Cómo se utiliza el panel "Console" y para qué es útil?
La consola permite ejecutar código JavaScript y también muestra errores o mensajes del programa. Es muy útil para encontrar problemas en una página.
15. ¿Qué información se puede obtener del panel "Network" y por qué es importante?
Permite ver las solicitudes que realiza una página al cargar archivos o información de Internet. Sirve para revisar tiempos de carga, errores y problemas de conexión.
